The project format, as proposed
Plain JSON, versioned from day one, read strictly. The folder is the unit of sharing; the project file lists what is in it so a missing file is reported rather than silently blank.

Moves out of the map file
materialsthe library, by stable id. A map keeps only the ids its voxels store.
texelDensityone resolution profile per project. Per-map override deferred until a map needs one.
filteringwith it.
Stays in the map file
structuresthe voxel volumes and sketches, with their paint.
objectsplaced sprites and their fields.
cameraan optional override of the project rig, and camera zones.
atmosphereper map.
Not in either
tile tagslive in the sheet's sidecar, so a sheet is portable between projects.
recents, last maplocal state in .papercut/, never shared.
