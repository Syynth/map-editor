What moved, and why

The frame is the same five regions as before. What changed is what each region is for.

Rail = subjects
Select, Terrain, Objects, Buildings, Fences. Each is a thing the artist works on, not a verb. The dot marks subjects that are planned but not built. Level settings live behind the gear at the bottom.
Select is first
It is the one tool that addresses what already exists, whatever made it. Voxel regions are its main subject: a shape (marquee, lasso, brush), a combine rule (replace, add, subtract), and verbs that act on the region itself (move, expand, contract, invert). Clicking an object selects it through the same tool.
Context bar = the active tool's controls
Mode switch first, then verbs with their keys, then parameters. Switching tools swaps the whole bar; each tool remembers its own settings.
Inspector = stacked, collapsible
Sections open for what the current tool cares about. Level is always there, closed, at the bottom.
Camera is not a tool
Orbit, pan and zoom are gestures in every tool. Reset view and Sweep sit in the top bar with the other level-wide actions.
Library, not verbs
New terrain types, object kinds and styles are entries in the level's library. Each subject's inspector shows its slice of it (Palette, Catalog) with an add row; the bar's chips are a view of the same list, so a new material is paintable the moment it exists. Level-wide import lives behind the gear.
Layer view
The slider on the right edge of the viewport is a slicer's layer range: two handles, upper and lower. Columns above the top are cut off, columns below the bottom ghost out, objects outside the range hide. ⌥ drag moves both handles to scrub one layer. It stays dim until narrowed.
Icons by default
Everything in the rail and the bars is icon-only — tools, verbs, modes, shapes, combine rules, library chips; the label and the key live in the tooltip. Only readouts (24 × 18) and menus that display a value (Shortcuts: Default) keep words. A preference under the Level gear turns labels on for anyone who wants them.
Keys are a preset
Every binding is data in the keymap. The Level bar exposes the preset (Default, Blender-like, Aseprite-like) so conventions from other apps can be swapped in without touching the tools.
