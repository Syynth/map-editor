Does dispatching every command through one place actually work?

In this editor, every action has a name — Raise Terrain, Choose Tool, Undo. A key, a menu item and an automated test all trigger the same named action, and they all go through one front desk that passes the request to whichever part of the editor handles it. This page lets you be the key presser and watch what the front desk does.

The question it exists to answer: does one front desk hold up when the part that should handle a request isn’t there? That is not an error case — it is normal. Play Mode only exists while you are playing, so “step one frame” has nowhere to go the rest of the time. The old way of building this broke the front desk permanently the first time it happened.
